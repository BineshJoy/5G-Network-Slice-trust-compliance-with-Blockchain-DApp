SECURITY MODEL

How the SLA Security Workflow Works

01

Read Live Configuration

The dashboard retrieves the active Open5GS slice, SMF, UPF, UE and SLA policy information.

02

Perform Real Test

The existing Python SLA engine measures actual bandwidth, latency and packet loss on the selected 5G slice.

03

Evaluate SLA

Each measurement is compared against the read-only SLA thresholds configured for that slice.

04

Record on Blockchain

The SLA measurement is permanently recorded and failed metrics generate corresponding violation records.
